### Ví dụ 1 luồng chạy thật: "Thêm nhân viên"

```
Frontend (gửi)   Employees.vue → EmployeeForm.vue → useEmployeeStore.js → employeeService.js
Backend (xử lý)  routes → auth:api → permission:employee.create → StoreEmployeeRequest
                 → EmployeeController → EmployeeService → EmployeeRepository → Employee
                 → EmployeeResource → JSON
Frontend (nhận)  store nhận response → toast + đóng modal → Employees.vue gọi lại GET, làm mới bảng
```

**4 chỗ có thể dừng sớm** (sai thì dừng ngay, không đi tiếp): (1) validate phía client (`formRef.value.validate()`) — sai thì 0 request gửi lên; (2) middleware `auth:api` — token sai → 401; (3) middleware `permission:employee.create` — thiếu quyền → 403; (4) `StoreEmployeeRequest` — data sai → 422. Càng dừng sớm càng đỡ tốn (mạng, Service/Repository, công viết lại validate ở Controller).

## 59. Cấp bậc vai trò — chặn gán vai trò cao hơn/ngang cấp

| Hạng mục | Chi tiết |
| --- | --- |
| Luật | Người tạo tài khoản cho nhân viên chỉ gán được vai trò có `roles.level` **thấp hơn** cấp cao nhất trong các vai trò của chính mình — cao hơn hay **ngang bằng** đều bị chặn 422. Thang bậc rời rạc `Role::LEVELS` = 0/20/40/60/80/100; mốc seed: Admin 100 · HR 60 · Manager 40 · Employee 20 (bậc 80 để trống sẵn cho cấp trên HR). |

| Xử lý Backend | [`RoleService::assignableRolesQuery()`](app/Services/RoleService.php) (định nghĩa DUY NHẤT của luật) + `assertCanAssign()` + `maxLevelOf()`; gọi từ [`EmployeeAccountService::assertCanAssignRoles()`](app/Services/EmployeeAccountService.php) (chặn thật) và [`RoleController::index()`](app/Http/Controllers/Api/V1/RoleController.php) (lọc sẵn ô chọn). |
| Giao diện Frontend | [`RoleForm.vue`](resources/js/views/Role/RoleForm.vue) ô **chọn** "Cấp bậc" (không cho nhập số tự do) và [`Roles.vue`](resources/js/views/Role/Roles.vue) cột "Cấp bậc" — cả hai lấy nhãn từ [`composables/roleLevels.js`](resources/js/composables/roleLevels.js) (bản mirror của `Role::LEVELS`, nhãn "ngang &lt;vai trò&gt;" chỉ là mốc tham chiếu theo vai trò seed). | Database & API | `roles.level` (`unsignedSmallInteger`, default 100) — [migration thêm cột](database/migrations/2026_10_01_000002_add_level_to_roles_table.php) rồi [migration chuẩn hóa về thang bậc](database/migrations/2026_10_01_000003_normalize_role_levels.php) (làm tròn LÊN khi ở giữa 2 bậc), [`RoleSeeder`](database/seeders/RoleSeeder.php) giữ cùng mốc. `level` nhận ở `POST/PUT /roles` (`sometimes|integer|in:Role::LEVELS`, gate `rbac.manage` nên chỉ Admin đổi được) và trả ở [`RoleResource`](app/Http/Resources/RoleResource.php) + `GET /roles`. |
